## 2. Категории обрабатываемых персональных данных

### 2.1. Данные Пользователя (физического лица, представляющего субъект хозяйственной деятельности):

фамилия, имя, отчество;

адрес электронной почты;

номер телефона;

данные платёжной карты (при проведении оплаты);

сведения о субъекте хозяйственной деятельности (юридическое лицо, ИП, самозанятый, физическое лицо), закреплённом за учётной записью (наименование, ИНН, иные реквизиты — если вводятся Пользователем).

### 2.2. Данные контрагентов (физических лиц), передаваемые Пользователем для работы в Сервисе:

фамилия, имя, отчество представителя контрагента;

должность;

контактные данные (номер телефона, email) — если требуются для направления документа и отправки СМС-кода подтверждения.

### 2.3. Технические данные, автоматически собираемые при использовании Сайта и PWA-приложения:

IP-адрес, информация о браузере, устройстве, файлы cookie (в том числе для сервисов аналитики, например, Яндекс Метрика).

Примечание: реквизиты организаций (наименование, ИНН, адрес, банковские реквизиты юрлица/ИП) не являются персональными данными и в настоящей Политике отдельно не регулируются.

## 3. Цели обработки

### 3.1. Персональные данные обрабатываются для следующих целей:

регистрация и авторизация Пользователя в Сервисе (в том числе в PWA-приложении);

предоставление доступа к функционалу Сервиса «Заведующая»;

исполнение договора (оформление подписки, оказание услуг по формированию и отправке документов);

проведение оплаты (взаимодействие с платёжным шлюзом Robokassa и иными платёжными агрегаторами);

направление документов контрагентам и отправка СМС-кодов подтверждения для подписания с применением простой электронной подписи (ПЭП);

обработка обращений и запросов Пользователя;

отправка информационных сообщений (при наличии явного согласия Пользователя);

анализ поведения пользователей для улучшения работы Сайта и Сервиса (на основании обезличенных технических данных).

## 4. Правовые основания обработки

### 4.1. Обработка персональных данных осуществляется на следующих правовых основаниях:

согласие Пользователя (например, при установке галочки «Согласен на обработку персональных данных» в форме, а также при использовании отдельных функций, предусматривающих рассылку);

необходимость исполнения договора между Оператором и Пользователем (в частности, для оказания услуг по формированию документов, отправки их контрагентам, приёма оплаты);

требования законодательства РФ.

В частности, обработка данных контрагентов производится на основании поручения Пользователя как оператора персональных данных (ст. 6 Федерального закона № 152-ФЗ) и исключительно в целях исполнения договора оказания услуг.

## 5. Порядок и условия обработки

### 5.1. Оператор осуществляет следующие действия с персональными данными: сбор, запись, систематизацию, накопление, хранение, использование, передачу, обезличивание, блокирование, удаление, уничтожение.

### 5.2. Данные хранятся в информационных системах Оператора, размещённых в облачной инфраструктуре Yandex Cloud на территории Российской Федерации.

### 5.3. Срок хранения персональных данных определяется целью обработки:

в течение срока действия договора и дополнительно 6 лет после его прекращения (для целей исполнения договора, учёта, отчётности, претензионной работы);

до момента отзыва согласия Пользователем (если иное не следует из иных законных оснований обработки).

### 5.4. При удалении учётной записи Пользователя персональные данные подлежат удалению в сроки, установленные внутренними регламентами Оператора, с учётом требований законодательства и обязательств по хранению документов.

## 6. Передача данных третьим лицам

### 6.1. Оператор может передавать персональные данные третьим лицам для исполнения обязательств по договору, в том числе:

платёжным сервисам (Robokassa и иные платёжные агрегаторы) — для проведения оплат;

операторам связи — для отправки СМС-кодов контрагентам;

поставщикам облачных и аналитических сервисов (Яндекс Метрика и др.) — для обезличенного анализа поведения пользователей;

иным подрядчикам — для обеспечения работоспособности и безопасности Сервиса.

### 6.2. Передача персональных данных третьим лицам осуществляется при условии заключения договора, обеспечивающего конфиденциальность и безопасность данных, и только в объёме, необходимом для выполнения конкретной функции.

### 6.3. Оператор не хранит данные платёжных карт Пользователей. Передача и обработка данных карт осуществляется платёжным сервисом в соответствии с требованиями стандартов безопасности (PCI DSS).

## 7. Особенности обработки данных контрагентов

### 7.1. При формировании документов в Сервисе Пользователь самостоятельно вносит персональные данные представителей контрагентов.

### 7.2. Оператор обрабатывает эти данные исключительно в целях функционирования Сервиса: формирование документа, направление контрагенту, отправка СМС-кода для подписания ПЭП, хранение подписанного документа в Личном кабинете.

### 7.3. Обработка осуществляется по поручению Пользователя как оператора персональных данных. Пользователь обязан обеспечить наличие правовых оснований для обработки персональных данных контрагентов до начала использования функционала Сервиса.

## 8. Меры безопасности

### 8.1. Оператор принимает организационные и технические меры для защиты персональных данных от неправомерного доступа, уничтожения, изменения, блокирования, копирования, распространения и иных неправомерных действий.

### 8.2. Хранение данных осуществляется в Yandex Cloud с соблюдением требований законодательства РФ, включая ФЗ № 152-ФЗ.

### 8.3. Доступ к данным имеют только уполномоченные сотрудники Оператора и подрядчики, заключившие соглашение о неразглашении.

### 9.1. Пользователь вправе:

запросить информацию о том, какие его данные обрабатываются;

потребовать исправления неточных данных;

потребовать прекращения обработки и удаления данных;

отозвать согласие на обработку (при этом Оператор прекратит обработку, если для неё нет иного законного основания, например, исполнение договора).

### 9.2. Для реализации этих прав Пользователь может направить обращение на контактный email Оператора.

### 9.3. Запросы на удаление или отзыв согласия рассматриваются в сроки, установленные законодательством.
